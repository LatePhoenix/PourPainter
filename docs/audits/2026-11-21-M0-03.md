## Findings
1. **[medium] `context.configure()` runs every frame.** `frame()` calls `configureContext()`, which reconfigures the swap chain 60 times a second even when nothing changed. That's wasted work, and it will matter once real passes run. Fix: configure once in `init`, and on resize only when the pixel size actually changes. Move the `configure` call inside the size-changed branch and drop the per-frame call. (→ M0-04)
2. **[low] `init()` doesn't recheck `disposed` after its `await`.** Under React StrictMode the first controller is disposed while `requestGpuDevice()` is still pending. It then finishes init anyway and configures the shared canvas context with its own device, before `App` disposes it a second time. This works today only because `App` compensates and the live controller reconfigures every frame (which finding 1 removes). Fix: after the await, if `this.disposed`, destroy the device and return. (→ M0-04)
3. **[low] `createRng(this.seed)` is called and the result thrown away** in `init` and `reset`. It's harmless and gets wired up once the sim uses randomness. Just don't forget it.
4. **[info] The clear-color comment says "linear-ish sRGB".** The canvas format is a non-sRGB `*8unorm`, so the values are written as sRGB, which is what we want. Fix the comment when the file is next touched.
5. **[info]** Chrome on Windows warns that `powerPreference` is ignored. This is harmless console noise.
