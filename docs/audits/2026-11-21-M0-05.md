## Findings
1. **[high for what comes next] The comparison helpers can't see NaN.** `Math.abs(NaN − x) > max` is always false, so NaN cells are skipped. The CPU-vs-GPU "Compare to CPU" harness (M1-02) and the symmetry test (M1-01) would both **report success on a solver that has blown up**, which is the worst failure mode for a checker. Fix: `maxAbsDiff` returns `NaN` (or `Infinity`) if any cell in either grid is non-finite, unless both are the same NaN/Inf, and `isMirrorSymmetric` returns `false` if a compared pair includes a non-finite value. Add tests for both. (→ M1-01, first criterion)
2. **[low] A fractional index reads as 0.** `getCell(1.5, y)` returns 0 as if it were out of bounds, which could hide off-by-half bugs in a solver. Fix: throw on non-integer indices (a CPU reference can afford the check), or document it. (→ M1-01)
3. **[info] The grid is Float32, as the task specified.** That's good for matching GPU precision in comparisons. `totalVolume` accumulates in float64, so the sum itself is accurate.
4. **[info] `src/sim/index.ts` re-exports the CPU test utilities** in the public sim barrel. It's harmless. Consider exporting them only from `src/sim/cpu` to keep the UI-facing surface small.
