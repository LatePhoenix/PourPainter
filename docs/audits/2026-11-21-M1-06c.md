## Verification performed
- **Fixture fidelity:** regenerated both fixtures from the live explicit solver and compared numerically with the committed files: **max |Δ| = 0** over all 4,096 cells each; steps 53 / 61 identical. (The text diff is large only because Prettier reflowed the committed JSON arrays.)

## Findings
1. **[low → Discovered] Fixtures can go stale without anyone noticing.** If `thinFilm.ts`/`grid.ts` (the explicit reference) changes, these tests keep comparing against the old field. Guard: store a hash of those source files in each fixture, and have the test fail with "regenerate fixtures (npx vite-node scripts/regen-semi-explicit-fixtures.ts)" when the hash differs. Cheap, and it turns staleness into a clear message.
2. **[info]** The regen script uses `vite-node`, which comes with Vitest, so it's not a new dependency.
