## Findings
1. **[low] The coordinate origin is bottom-left (y-up).** That's a reasonable choice, but DOM pointer events and WebGPU texture coordinates are both y-down, so it's an easy source of upside-down bugs. Fix: one `pointerToCanvas()` / `canvasToTexel()` conversion pair in `src/sim`, used everywhere. (Added as a criterion on M0-03.)
2. **[low] `serializeRecipe` doesn't validate.** The app could save a recipe that it then refuses to load. Fix: call `validateRecipe` before serializing, or at the save point in the UI later. (Added to Discovered.)
3. **[info] `src/sim/index.ts` re-exports `isValidSeed` from domain.** It's harmless, but it gives callers two import paths for the same function. Leave it or remove it at the next barrel touch.
